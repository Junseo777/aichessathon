# Syzygy endgame tables, 3 and 4 pieces

70 files: the 35 three- and four-piece endings (kings included), each as a WDL
table (`.rtbw`, win/draw/loss) and a DTZ table (`.rtbz`, distance to zeroing).
Generated by Ronald de Man's tbgen; downloaded 2026-09-06 from the Lichess mirror,

    https://tablebase.lichess.ovh/tables/standard/3-4-5-wdl/<name>.rtbw
    https://tablebase.lichess.ovh/tables/standard/3-4-5-dtz/<name>.rtbz

The mirror publishes no checksums. Each file's size matched the mirror's directory
listing on download, python-chess opens all 70 (it checks the magic bytes), and
`chessml/tests/test_tablebase.py` probes known results through them. `CHECKSUMS.txt`
holds sha256 sums of the files as downloaded, for byte-for-byte comparison later.

Read by `chessml/tablebase.py` through python-chess, which the platform preinstalls.
Ships in the zip (`harness/package.py` includes this directory); the rules allow
tablebases within the 50 MB unzipped cap. The five-piece set is about a gigabyte
and stays out.
